단말기 다운로드
가맹점에 카드 단말기 설정을 내려주는 업무
  • 1가맹점 TID(단말기 번호) 확인
  • 2단말기 기종 확인 (기종마다 다운로드 방식이 달라요)
  • 3PG사 시스템에서 해당 TID로 다운로드 요청
  • 4가맹점에 완료 안내 또는 현장 확인
참고 — 단말기 기종이 여러 종류 있어요. 처음에는 기종별 다운로드 방법을 따로 정리해달라고 요청해두면 좋아요.

가맹점 응대
문의·불만·오류 대응
  • •결제 오류 문의 → 오류 내용 메모 후 PG사 확인 → 가맹점에 결과 안내
  • •정산 문의 → 정산일·금액 확인 후 안내 (모르면 담당자에게 먼저 확인)
  • •단말기 오작동 → 재다운로드 먼저 시도, 해결 안 되면 AS 접수
  • •가맹점 정보 변경 (계좌·주소 등) → 변경 서류 접수 후 처리
응대 기본 원칙 — 바로 답을 모를 때는 "확인 후 연락드리겠습니다"가 "모르겠습니다"보다 훨씬 낫습니다. 확인하고 꼭 다시 연락하세요.
정산 주기

가맹점마다 계약된 정산 주기가 달라요. 문의 시 먼저 해당 가맹점의 정산 유형을 확인하세요.

D+1
익일 정산
결제일 다음 영업일에 정산. 가장 일반적인 유형이에요.
D+0
실시간 정산
결제 즉시 정산. 즉결이라고도 부릅니다.
주의 — 공휴일·주말은 영업일에서 제외돼요. D+1 가맹점이 금요일 결제하면 월요일 정산입니다.
문의 유형별 대응 스크립트
가맹점
"결제가 안 돼요 / 오류가 났어요"
담당자
"네, 불편드려서 죄송합니다. 어떤 오류 메시지가 뜨는지 확인해 주시겠어요?"
담당자 (확인 후)
"확인해보고 바로 연락드리겠습니다." → PG사 문의 후 결과 안내
오류 코드나 메시지를 반드시 메모해두세요. PG사에 문의할 때 필요해요.
가맹점
"정산이 아직 안 들어왔어요 / 금액이 다른 것 같아요"
담당자
"확인해드리겠습니다. 상호명과 결제일 알려주시겠어요?"
담당자 (확인 후)
D+1: "○○일 결제 건은 ○○일 정산 예정입니다."
D+0: "실시간 정산 가맹점으로, 결제 즉시 입금됩니다. 입금 내역 다시 확인 부탁드려요."
정산 유형(D+1 / D+0)을 먼저 파악한 뒤 안내하세요. 공휴일 이슈도 함께 확인.
가맹점
"단말기가 이상해요 / 작동이 안 돼요"
담당자
"TID 번호 확인 후 재다운로드 먼저 진행해볼게요. 잠시만요."
담당자 (재다운로드 후)
해결 시: "다운로드 완료됐습니다. 다시 확인해보시겠어요?"
미해결 시: "AS 접수 진행해드리겠습니다. 방문 일정 조율해드릴게요."
재다운로드로 해결 안 되면 혼자 해결하려 하지 말고 바로 AS 접수하세요.
가맹점
"계좌번호 / 주소가 바뀌었어요"
담당자
"변경 처리해드리겠습니다. 변경된 통장사본 전달해주시면 바로 진행할게요."
담당자 (서류 수령 후)
"서류 확인됐습니다. 처리 완료되면 다시 안내드리겠습니다."
계좌 변경은 통장사본 필수. 처리 후 가맹점에 완료 안내 꼭 하세요.
전산 등록 절차 (Paytree 어드민)

가맹점 1개를 등록하려면 아래 4단계를 순서대로 진행해야 해요.
어드민 주소: admin.toncompany.net

① PG정보 등록→ ② 영업대행(AID) 등록→ ③ 단말기 등록→ ④ 가맹점 등록
①
PG정보 등록
상위 PG사에서 받은 MID 키값 등록 — 최초 1회만
  • 1기본정보 → PG정보관리 → 등록 클릭
  • 2PG사 선택 (주로 네스트페이), PG MID / PG 터미널번호 / PG KEY 입력
  • 3인증방법 선택: 단말기 = 카유 (카드번호+유효기간) / 수기 = 카유비생 (카드번호+유효기간+생년월일+카드비밀번호)
참고 — PG코드: 네스트페이 31 / 페이투스 32 / 유니윌 위즈페이 33 / 코페이 34 / 웰컴페이먼츠 35
②
영업대행(AID) 등록
지사/총판/대리점 등 영업자 정보 등록
  • 1기본정보 → 영업대행 정보관리 → 등록/변경/조회 → 등록 클릭
  • 2AID 입력 (형식: 지사 jpay0+4자리 / 총판 cpay0+4자리 / 대리점 dpay0+4자리 / 영업점 ypay0+4자리)
  • 3AID명(상호명), 구분(지사/총판 등), 사업자 유형 선택
  • 4정산정보 입력: 정산은행·계좌·예금주, 정산주기(월1회 기본), 정산방법(지사정산), 세금계산기준
  • 5저장 후 AID명 클릭 → 수수료 설정 탭에서 od(실시간)/sd(익일) 수수료 등록
사업자 유형 구분
개인/법인사업자 → 계산서 발행 가능 · 세금 미차감
비사업자(누락영업자) → 계산서 발행 불가 · 부가세+원천세 차감
⚠ 세금계산 기준은 정산팀 확인 후 등록 — 잘못 적용 시 민원 발생
③
단말기 등록
가맹점에 설치할 단말기 정보 등록
  • 1기본정보 → 단말기관리 → 등록 클릭
  • 2제품번호(시리얼번호) 입력 — 필수값
  • 3단말기 종류에 따라 구분:
    · 삼성페이 비인증: PG사=네스트페이, 단말기번호=카테카 채번 TID
    · 인증 단말기: PG사=해당 PG사, 단말기번호=카테카 채번 TID
    · 비인증 단말기: PG사=해당 PG사, 단말기번호=공란(자동생성)
  • 4다건 등록 시 메인화면 → 파일형식 다운로드 → 엑셀에 제품번호·PG코드 입력 후 업로드
단말기 사용료 — 무선 1대 11,000원 / 유선 1대 20,000원 (가맹점 정산에서 차감)
④
가맹점 등록
기본정보 → 가맹점정보관리 → 등록
  • 1사업자정보: OD가맹점=가맹점 사업자번호 / SD가맹점=상위PG 사업자번호. 상호명·대표자명·주소 계약서대로 입력
  • 2가맹점정보: MID 입력 후 중복확인, MID명(가맹점명), 전화번호, 계약담당자1=본인
  • 3영업점정보: 지사→총판→대리점→영업점 순서로 찾기 버튼으로 각각 연결, 수수료 선택
  • 4정산정보 입력:
    · 정산방법: 직접정산(계좌) / 지갑정산 / PG정산 중 선택
    · 지급대행사: 즉결=페이네스트 / 익일=쿠콘
    · 취소기능: 익일=미설정(정산전취소) / 즉결=불가능
    · 송금수수료: 별도 안내 없으면 550원
    · 수수료 정산기준:선취 / 계산기준:절사 / 등록기준:VAT포함 (변경 불필요)
  • 5가맹점 한도: 기본 월한도 2억 / 일한도 2천만 / 1회한도 300만원
  • 6저장 후 → 결제서비스 정보에서 사용여부 미사용→사용 변경, 정산주기·할부개월수 설정
  • 7PG정보 보기 버튼 클릭 → 해당 PG정보 연결 → 완료
⚠ 가맹점 상태 — 등록 후 상태는 중지로 설정, 관리자 사용승인 후 익일 10시 오픈으로 가맹점에 안내
SD vs OD — SD: 비사업자, 매출신고 미신고 / OD: 개인·법인사업자, 매출신고 신고
+
피플(P플) 계정 생성
전산 등록 후 피플 관리자에서 가맹점 앱 계정도 함께 생성
  • 1피플 관리자 → 회원관리 → 회원등록
  • 2아이디: 전산 MID에서 마지막 m 제외한 값 (예: gpay7772sm → gpay7772s)
  • 3회원유형: 반드시 사업자회원으로 등록 (미설정 시 저장 안 됨)
  • 4가맹점에 앱(P플) 설치 안내 및 초기 비밀번호 전달 (초기 PIN번호: 000000)
참고 — 피플 앱과 웹관리자 계정은 호환되지 않아요. 각각 별도 비밀번호 사용.
